# Claude Skills

custom skills for Claude, covering cybersecurity study, tech and automotive content creation, career development, and general dev/writing workflows.

## Skills

| Skill | Purpose |
|---|---|
| `aiyubovan-ikigai` | Guides business idea discovery using the Ikigai framework: market analysis, positioning, offer design. |
| `ats-cv-builder` | Creates, audits, and tailors ATS-friendly CVs from user details, existing CVs, or job descriptions. Exports to DOCX/PDF. |
| `coding` | Software engineering: code generation, review, debugging, testing, architecture. |
| `cybersecurity-ai-career-mentor` | Long-term mentor for cybersecurity + AI career paths: labs, certifications, portfolio, job readiness. |
| `cybersecurity` | Defensive security analysis: threat modeling, secure configuration, vulnerability assessment, incident response. |
| `github` | GitHub workflows: repos, branches, issues, pull requests, reviews, releases, CI/CD. |
| `image-generation` | AI image prompt design: composition, camera, lighting, consistency, iteration. |
| `manula-context` | Personal/professional context for Manula Nirwan (cybersecurity student, tech entrepreneur, content creator, automotive YouTuber). Applied selectively to relevant tasks. |
| `professional-email` | Drafts professional emails from a described situation: follow-ups, proposals, declines. |
| `project-management` | Project planning: requirements, task breakdown, milestones, risk tracking. |
| `prompt-engineering` | Designs and evaluates prompts for text, image, video, coding, and agent tasks. |
| `research` | Web research, source checking, fact verification, evidence synthesis. |
| `seo` | SEO for YouTube, blogs, and websites: titles, descriptions, keywords, search intent. |
| `social-media-posts` | Writes social posts (caption, hashtags, thumbnail prompt, posting time) for Facebook, Instagram, TikTok, YouTube Shorts. |
| `study-helper` | Converts class notes into a study guide: summary, key points, likely exam questions, plain-language explanations. |
| `video-generation` | AI video prompt design: shot planning, continuity, camera motion, timing. |
| `web-development` | Frontend/backend development: APIs, databases, auth, deployment, performance, accessibility. |
| `writing` | Professional writing: articles, scripts, documentation, reports, proposals. |
| `youtube-content` | YouTube strategy: hooks, titles, descriptions, chapters, scripts, retention. |

## Usage

Each file is a `SKILL.md` with YAML frontmatter (`name`, `description`) defining when Claude should trigger it, followed by the skill's instructions.
