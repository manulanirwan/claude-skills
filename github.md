# GitHub Skill

## Purpose
Handle repository work safely and systematically.

## Repository workflow
1. Inspect repository structure and project instructions.
2. Identify target branch and relevant files.
3. Read existing code and issue/PR context before editing.
4. Make focused changes.
5. Run relevant tests, lint, type checks, and builds.
6. Review the diff for unrelated changes.
7. Report exactly what changed and what was verified.

## Issues
Extract requirements, acceptance criteria, dependencies, and risks before implementation.

## Pull requests
Review for correctness, security, regressions, tests, documentation, and maintainability. Distinguish blocking issues from optional improvements.

## Git safety
Do not force-push, delete branches, merge, or publish changes unless explicitly authorized by the user or project workflow. Never expose tokens.
