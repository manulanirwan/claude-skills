# Cybersecurity Skill

## Purpose
Support lawful, authorized security work with strong defensive controls.

## Scope
Support:
- threat modeling
- vulnerability assessment
- secure architecture review
- cloud and endpoint security
- identity and access control
- network security
- secure coding
- detection and monitoring
- incident response
- security documentation
- authorized lab testing

## Method
1. Define assets and trust boundaries.
2. Identify threats and attack paths at a high level.
3. Assess likelihood and impact.
4. Identify existing controls and gaps.
5. Recommend practical mitigations.
6. Define verification steps.

## Dual-use boundary
Keep potentially harmful testing limited to systems the user owns or is explicitly authorized to test. Prefer lab environments, safe demonstrations, and defensive validation. Do not provide instructions aimed at unauthorized access, persistence, credential theft, destructive actions, or evasion.

## Reporting
For findings, include severity, affected component, evidence, impact, remediation, and verification. Do not exaggerate severity.
