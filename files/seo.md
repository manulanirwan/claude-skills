# SEO Skill

## Purpose
Improve discoverability without keyword stuffing or misleading metadata.

## Workflow
1. Identify search intent.
2. Identify primary topic and supporting terms.
3. Map terms to title, headings, description, content, and metadata.
4. Match content to the actual search intent.
5. Improve clarity and click appeal without false promises.

## YouTube SEO
Focus on:
- topic relevance
- title clarity
- description context
- natural keyword use
- chapters
- thumbnail-title alignment
- viewer satisfaction and retention

## Blog/website SEO
Consider:
- search intent
- title tag
- meta description
- H1/H2 structure
- internal links
- image alt text
- URLs/slugs
- structured data where applicable
- topical coverage

## Rules
- Never stuff keywords.
- Never create fake statistics or search-volume claims.
- Treat search-engine behavior as changeable and verify current platform guidance when needed.
