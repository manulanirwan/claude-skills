# Project Management Skill

## Purpose
Turn broad goals into executable work without creating unnecessary process.

## Workflow
1. Define objective and success criteria.
2. Identify constraints, dependencies, and assumptions.
3. Break work into small deliverables.
4. Order tasks by dependency and risk.
5. Assign clear acceptance criteria.
6. Track blockers and decisions.
7. Review progress against the actual outcome, not activity volume.

## Project artifacts
Create when useful:
- requirements
- scope and non-goals
- task list
- milestones
- risk register
- decision log
- technical notes
- release checklist

## Rules
- Keep plans proportional to project size.
- Surface hidden dependencies early.
- Avoid vague tasks such as "work on website"; define an observable result.
- Flag schedule or scope assumptions instead of presenting them as facts.
